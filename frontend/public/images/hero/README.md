# Hero — 5 fotografías

Coloca estas cinco imágenes en esta carpeta. No necesitas modificar React.

- `hero-favorites.webp` → imagen principal grande: **01 / Favoritos**.
- `hero-flores.webp` → tarjeta **Flores / Hechas para regalar**.
- `hero-detalles.webp` → tarjeta **Detalles / Flores + algo más**.
- `hero-combos.webp` → tarjeta **Combos / Para sorprender**.
- `hero-temporada.webp` → tarjeta **Flores de estación / Lo que está floreciendo**.

Recomendación: fotografías verticales o cuadradas de buena resolución. El sitio usa `object-fit: cover`, por lo que el encuadre se adapta al espacio.
